# CS1101S: Programming Methodology (Y1S1)

CS1101S, Programming Methodology, is a foundational course aimed at developing a deep understanding of computer programs, fostering programming skills, and cultivating an appreciation for computer science [source:cs1101s-lecture-lecture-l1-print-pdf#section-1]. Originating from MIT's "Structure and Interpretation of Computer Programs" (SICP) in the 1980s, the module emphasizes experiential learning through the Source Academy platform [source:cs1101s-lecture-lecture-l1-view-pdf#section-1]. A core problem-solving methodology is taught, encompassing five steps: Read the Question, Play, Think, Program, and Test [source:cs1101s-brief-brief-b12-view-pdf#section-1].

The module is structured into four main units:
*   **Unit 1: Functions** – Covers functional abstraction, the substitution model, and recursive processes [source:cs1101s-cs1101s-extra-lecture-l11-print-pdf#section-1]. Applications include Runes and curves [source:cs1101s-lecture-lecture-l11-view-pdf#section-1].
*   **Unit 2: Data** – Focuses on data abstraction, pairs, lists, trees, searching, and sorting [source:cs1101s-cs1101s-extra-lecture-l11-print-pdf#section-1].
*   **Unit 3: State** – Introduces stateful abstractions, mutable data, arrays, loops, and the environment model [source:cs1101s-cs1101s-extra-lecture-l11-print-pdf#section-1].
*   **Unit 4: Beyond** – Explores advanced topics like streams, metalinguistic abstraction, and different programming paradigms [source:cs1101s-cs1101s-extra-lecture-l11-print-pdf#section-1].

## Key Concepts

Throughout CS1101S, students engage with fundamental computer science concepts:

*   **Models of Computation**: The module progresses from the [substitution model](y1s1-cs1101s-lecture-02) for evaluating pure functions to the [environment model](y1s1-cs1101s-lecture-08) for handling state [source:cs1101s-lecture-lecture-l2-print-pdf#section-1, cs1101s-lecture-lecture-l8-view-pdf#section-1]. This includes exploring [notional machines](y1s1-cs1101s-lecture-12d-meta-circular-evaluator-notional-machine) to understand program execution on hardware [source:cs1101s-lecture-lecture-l12d-part-2-pdf#section-1].
*   **Complexity Analysis**: Time and space complexity are measured using Big-O (O) and Big-Theta (Θ) notations to characterize the order of growth of algorithms. This distinguishes recursive processes (which may have growing call stacks) from iterative processes (often achieving O(1) space) [source:cs1101s-5border-pdf#section-1, cs1101s-cheatsheet-cs1101s-keagan-pdf#section-1, cs1101s-studio-studio-s3-pdf#section-1]. Recurrence relations are used to analyze runtime [source:cs1101s-cheatsheet-pdf#section-1, cs1101s-recurrence-relations-pdf#section-1].
*   **Data Structures**: Fundamental structures like [pairs](y1s1-cs1101s-lecture-04), [lists](y1s1-cs1101s-lecture-05), and [trees](y1s1-cs1101s-lecture-05) are covered, along with [arrays](y1s1-cs1101s-lecture-07) and [streams](y1s1-cs1101s-lecture-10) [source:cs1101s-lecture-lecture-l4-print-pdf#section-1, cs1101s-lecture-lecture-l5-revised-print-pdf#section-1, cs1101s-brief-brief-b8-view-pdf#section-1, cs1101s-lecture-lecture-l10-view-pdf#section-1].
*   **Algorithms**: The course delves into [searching algorithms](y1s1-cs1101s-lecture-06) (linear, binary), [sorting algorithms](y1s1-cs1101s-lecture-06) (selection, insertion, merge, bubble sort), and optimization techniques like [memoization](y1s1-cs1101s-lecture-09) [source:cs1101s-lecture-lecture-l6-view-pdf#section-1, cs1101s-lecture-lecture-l9-view-pdf#section-1, cs1101s-reflection-reflection-r9-pdf#section-1, cs1101s-studio-studio-s10-pdf#section-1].
*   **Programming Paradigms**: Beyond functional programming, the module introduces [mutable/stateful programming](y1s1-cs1101s-lecture-07), [logic programming](y1s1-cs1101s-lecture-12a-logic-programming), and [concurrent programming](y1s1-cs1101s-lecture-12b-concurrent-programming) [source:cs1101s-lecture-lecture-l7-updated-view-pdf#section-1, cs1101s-lecture-lecture-l12a-view-pdf#section-1, cs1101s-lecture-lecture-l12b-view-pdf#section-1].

## Assessment Structure

The assessment for CS1101S typically comprises various components, designed to evaluate both theoretical understanding and practical programming skills:
*   **Source Academy Achievements**: 18% (e.g., 0.5% per level up to Level 36) [source:cs1101s-practical-cs1101s-programming-methodology-pdf#section-1].
*   **Studios**: 5% (3% for attendance, 2% for effort) [source:cs1101s-practical-cs1101s-programming-methodology-pdf#section-1].
*   **Reflection Attendance**: 5% [source:cs1101s-practical-cs1101s-programming-methodology-pdf#section-1].
*   **Reading Assessments (RA1, RA2)**: 6% each, typically closed-book multiple-choice questions covering scoping, processes, and program evaluation [source:cs1101s-practical-cs1101s-programming-methodology-pdf#section-1, cs1101s-ra1-practice-reading-assessment-ra1-2021s1-pdf#section-1, cs1101s-ra2-reading-assessment-ra2-2021s1-pdf#section-1].
*   **Mastery Checks (MC1, MC2)**: 3% each, oral pass/fail tests conducted in small groups [source:cs1101s-practical-cs1101s-programming-methodology-pdf#section-1, cs1101s-brief-brief-b3-view-pdf#section-1].
*   **Midterm Assessment**: 12%, typically covering functional and data abstraction [source:cs1101s-practical-cs1101s-programming-methodology-pdf#section-1].
*   **Practical Assessment**: 12%, often involves programming tasks using concepts like mutable data or advanced data structures [source:cs1101s-practical-cs1101s-programming-methodology-pdf#section-1, cs1101s-practical-pa-1617s1-pa-1617s1-pdf#section-1].
*   **Final Assessment**: 30% [source:cs1101s-practical-cs1101s-programming-methodology-pdf#section-1].
