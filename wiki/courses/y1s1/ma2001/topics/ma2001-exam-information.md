# MA2001 Examination Information

The MA2001 final examination assesses students' understanding and application of linear algebra concepts covered throughout the course, with specific guidelines regarding format, allowed materials, and answering methods [source:ma2001-exam-information-pdf#section-1].

### Examination Details

*   **Date and Time**: The examination is scheduled for November 23, 2022 (Wednesday), from 1 pm to 3 pm, allowing 2 hours for completion [source:ma2001-exam-information-pdf#section-1].
*   **Venue**: Venues will be announced [source:ma2001-exam-information-pdf#section-1].
*   **Topics Covered**: All topics taught in the module are included, with the exception of quadratic forms (Section 6.4) and geometric transformations (Section 7.3) [source:ma2001-exam-information-pdf#section-1].

### Permitted Materials

Students are allowed to bring the following materials into the examination:
*   **Helpsheet**: One A4-sized, double-sided helpsheet [source:ma2001-exam-information-pdf#section-1].
*   **Calculators**: Any type of calculator may be used, provided it is not capable of communication or web-surfing. All computational steps must be shown [source:ma2001-exam-information-pdf#section-1].

### Question Structure

The examination consists of six questions, all of which must be answered [source:ma2001-exam-information-pdf#section-2].
*   **First Four Questions**: These are primarily computational problems [source:ma2001-exam-information-pdf#section-2].
*   **Last Two Questions**: These are mainly theoretical problems, which may be partly similar to homework/tutorial questions and partly unseen [source:ma2001-exam-information-pdf#section-2].

### Computational Questions: Key Areas

Students should practice extensively to correctly perform the algorithms and methods for the following computational problems [source:ma2001-exam-information-pdf#section-3, ma2001-exam-information-pdf#section-4]:
*   **Gaussian and Gauss-Jordan Eliminations**: Performing these operations correctly.
*   **Solving Linear Systems**: Solving systems of linear equations and determining their consistency. See [[linear-systems-solution-types]] for more details.
*   **Inverse of a Square Matrix**: Finding the inverse of a square matrix. See [[invertible-elementary-matrices]] for more details.
*   **Spanning Subspaces**: Finding a set of vectors that spans a given subspace. See [[linear-combinations-span]] for more details.
*   **Linear Independence**: Determining whether given vectors are linearly independent. See [[linear-independence-bases]] for more details.
*   **Subspace Verification**: Checking if a given set is a subspace. See [[vector-spaces-subspaces-intro]] for more details.
*   **Basis and Dimension**: Finding a basis for a given subspace and determining its dimension. See [[linear-independence-bases]] and [[dimension-rank-nullity]] for more details.
*   **Transition Matrix**: Finding the transition matrix from one basis to another.
*   **Gram-Schmidt Process**: Performing the Gram-Schmidt process. See [[gram-schmidt-process]] for more details.
*   **Least Squares Solutions**: Finding a least squares solution to a linear system. See [[least-squares-solutions]] for more details.
*   **Vector Projections**: Finding the projection of a vector onto a subspace. See [[orthogonal-sets-projections]] for more details.
*   **Matrix Diagonalization**: Diagonalizing a square matrix. See [[diagonalization]] for more details.
*   **Orthogonal Diagonalization**: Orthogonally diagonalizing a symmetric matrix.
*   **Standard Matrix of a Linear Transformation**: Using the standard matrix of a linear transformation. See [[standard-matrix-linear-transformation]] for more details.

### How to Answer Exam Questions

Specific rules apply to answering questions in this module's examination [source:ma2001-exam-information-pdf#section-5, ma2001-exam-information-pdf#section-6, ma2001-exam-information-pdf#section-7]:
*   **"Write down" or "True or not" questions**: If a question asks to "write down" something, or to state whether something is "true or not" without justification, only the answer is required, without explanation [source:ma2001-exam-information-pdf#section-5].
*   **"Find" or "Determine" questions**: For questions asking to "find" or "determine" something, steps of computation must be shown to demonstrate the method used, unless the answer is trivial [source:ma2001-exam-information-pdf#section-5].
*   **Computational Answers**: Most computational answers are expected to be integers. If not, answers should be expressed in fractions and/or square roots (e.g., $3/2, \sqrt{5}, 1/\sqrt{3}$) [source:ma2001-exam-information-pdf#section-6].
*   **"Show" or "Prove" questions**: A detailed proof is required for questions asking to "show" or "prove" something [source:ma2001-exam-information-pdf#section-6].
*   **Theoretical Questions using Theorems**: When answering theoretical questions that require the use of a theorem or result from the textbook, it is not necessary to cite the theorem number. However, the conditions leading to the conclusion must be clearly stated [source:ma2001-exam-information-pdf#section-6].
*   **Theoretical Questions using Homework/Tutorial Results**:
    *   If a homework/tutorial result directly provides the conclusion, the proof of that result must be reproduced [source:ma2001-exam-information-pdf#section-7].
    *   If the result is only part of a longer proof, it can be used without reproducing its proof. It is recommended to state "by the result of a homework/tutorial question" [source:ma2001-exam-information-pdf#section-7].
